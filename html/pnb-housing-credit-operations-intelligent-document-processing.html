The Challenge

Underwriters were reading, re-keying and reconciling

Each home-loan file carries a dozen or more documents in different formats. Before any credit judgement, someone had to sort them, type the key numbers into the system and check that they agree with each other.

Many document types

Identity proofs, salary slips, Form 16, bank statements, sale agreements, title deeds and plans, all as scans.

Manual re-keying

Names, incomes, addresses and values typed in by hand, with typos that surface later.

Late inconsistencies

A name variant, a salary that doesn't match the bank credit or a different tower number on the title, found late or not at all.

Judgement squeezed

Most of the underwriter's time went into reading, leaving less for the actual credit decision.

Read, check, explain, with a human in the loop

The Solution

Five things the assistant does with every file

One synthetic loan file runs through all five modules. Pick a scenario in module 02 and the questions, answers and credit note in later modules change with it.

01 · Read the file

Sort every page, then pull out every field

Eleven scanned pages arrive in random order. Press Process: each page is classified into a document type, then each document is read and its fields extracted as structured data with a confidence score.

Extracted fields · JSON

Synthetic applicant and documents; identity numbers masked.

02 · Cross-check the documents

Ten checks, each explained in plain language

Choose a scenario and run the checks. The assistant compares fields across documents, applies policy rules and explains every result with its sources.

File readiness

Pass = consistent. Review = explainable difference for a human to confirm. Fail = must be resolved before sanction.

03 · Ask the file

Questions answered from the file, with citations

Ask in plain English. The assistant retrieves the most relevant passages from this file, answers only from them and cites each source. Try asking something the file can't answer.

Retrieved passages

Passages used for the answer appear here, ranked by similarity.

04 · Underwriter's desk

A draft credit note, and a dial for human review

Generate the draft note for the current scenario. Then set the confidence threshold: fields below it go to a human reviewer. Higher thresholds mean fewer errors slip through, but less straight-through processing.

Key Takeaways

What any lender can borrow

01

Extract to a schema, not to prose

Structured fields with confidence scores are what make checks, routing and audit possible.

02

Cite everything

Underwriters trust an answer they can trace to a page; guardrails keep the assistant inside the file.

03

Keep the human on the decision

Let GenAI read and reconcile; let thresholds route doubt to people, and leave credit judgement with them.

The Challenge

Thousands of signatures, trapped on paper

The project for the Ministry of Skill Development and Entrepreneurship needed every respondent's contact validated. The evidence was a signature, captured in the field on A4 sheets, one row per respondent.

Signatures on A4

Respondents signed printed sheets in the field. Each sheet held dozens of rows from different employers and states.

Noisy, creased scans

Image quality varied. Folds and creases cut across rows, and scans were uneven in light and angle.

One image per respondent

Validation needed each signature as its own file, named exactly after the respondent, so it could be matched to their contact.

200 hours of snipping

Crop, paste, rename, save, check, repeat. Done by hand, the full set would take about 200 hours, with misnamed files along the way.

HMC Approach

Keep the human eye, automate everything around it

Automatic signature detection was unreliable on creased scans, so a person still frames each signature. The macro does the rest: naming, saving, highlighting and moving on.

Select a step to see what happened.

Discover · Time the manual way

We timed analysts cropping signatures by hand.

  • About 2 minutes per signature: crop, paste, rename, save and check.
  • Most errors were naming errors: the right image under the wrong respondent.
  • Creases and noise defeated automatic detection on many sheets.

Deliverable: Time-and-error baseline.

Design · Person frames, macro files

Split the task: judgement for a person, routine for the macro.

  • The scanned sheet sits next to the respondent list in Excel.
  • Names come from the list, in order, never typed.
  • Guard checks before every save: path exists, path valid, exactly one capture.

Deliverable: Flow chart and UserForm layout.

Build · SAVE SIGNATURES form

A small UserForm with two buttons and a path box.

  • SAVE: picks the name from the cell, pastes the capture, exports it as an image named after the respondent, highlights the row and moves to the next name.
  • RESET: deletes the last capture and steps the name index back.
  • Clear message boxes for a missing path, a wrong path or no capture.

Deliverable: Macro-enabled workbook and form.

Adopt · Ten-minute training

Analysts were productive the same day.

  • Set the destination folder once per batch.
  • Snip, SAVE, snip, SAVE; RESET only when a capture is wrong.
  • Highlighted rows show progress at a glance.

Deliverable: One-page guide.

Scale · Every state, same tool

Batches were split by state, such as AP & Telangana, and run in parallel.

  • One folder per state and employer.
  • File names matched the respondent list exactly for validation.
  • 200 hours of work finished in about 8.

Deliverable: Named signature library for validation.

Key Takeaways

What any research team can borrow

01

Automate around the judgement

When scans are too messy for full automation, keep the person on the hard bit and automate every step around it.

02

Never type a name twice

Taking names from the respondent list removed the most common error: the right image under the wrong name.

03

Make undo one click

RESET made mistakes cheap to fix in the moment, instead of costly to find during validation.

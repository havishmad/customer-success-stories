The Challenge

A good machine, hard to show

The robotics team was taking the AG-3X three-axis gantry to customers. The engineering was solid; explaining it was the bottleneck.

CAD stays in CAD

Design files needed licensed software and powerful laptops. Customers and sales could not open them.

Static renders, no motion

Slides showed the gantry, not how X, Y and Z move, or what the gripper does through a pick cycle.

Animation was slow

An outsourced walkthrough took weeks, and every design change meant paying for a re-render.

Training waited for steel

Operators and service teams could only learn the machine once a physical unit existed.

HMC Approach

From spec sheet to spinning model

Engineers supplied the facts. GenAI wrote the 3D code. The result is a single web file anyone can open.

Select a step to see what happened.

Discover · Who needs to see the machine, and what?

We talked to sales, design, service and training about what each wanted to see.

  • Collected the spec sheet, BOM and reference images for the AG-3X.
  • Listed the questions customers ask most: stroke, payload, repeatability, drives and safety.
  • Agreed the must-haves: motion on all three axes, an exploded view and labelled parts.

Deliverable: Model brief and source data pack.

Design · Storyboard the build

The model follows how the machine is built, so it doubles as a teaching tool.

  • Five build stages: frame, motion axes, drive train, end effector, controls.
  • Every label taken from the BOM: part name plus its key spec.
  • Controls chosen to match a real pendant: jog X, Y, Z, gripper and a demo cycle.

Deliverable: Storyboard and component label list.

Build · GenAI writes the 3D code

The model was written as code with Claude, not exported from CAD.

  • Claude generated a single-file WebGL scene with Three.js, iterated from the storyboard.
  • Detail added round by round: T-slot profiles, belts, drag chain, nameplates, PLC and drives.
  • Engineers reviewed proportions and labels against the spec at each round.

Deliverable: AG-3X interactive model, about 80 KB, no install.

Adopt · Put it in front of people

The model went straight into the team's daily work.

  • Sales opens it on a laptop or phone in customer meetings, then shares the link.
  • Design reviews use the exploded view to discuss specific sub-assemblies.
  • Operators and service staff walk through the build stages before the machine arrives.

Deliverable: Demo script and a sharing guide for sales.

Scale · A template for the portfolio

The same pattern now applies to other stations and cells.

  • The AG-3X build becomes the template for future machine models.
  • Labels and specs are kept in step with the BOM as designs change.
  • The robotics team is trained to brief and review new models themselves.

Deliverable: Model template, prompt pack and review checklist.

Key Takeaways

What transfers to any machine builder

A link beats a render

02

Let the BOM drive the model

The Challenge

A style guide nobody could check at scale

Studio shoot, manual review against the style guides, then the bottleneck: slow, subjective and error-prone checks before new SKUs could go live.

Thousands of raw images

Every season, every category, from several studios and agencies.

Massive style guides

Sequence, shot types, framing, creases and backgrounds differ by category and season.

Hours of manual QA

QA teams compared each image to the guide by eye, set by set.

Subjective and late

Different reviewers, different answers; reshoots found after the set was struck.

HMC Approach

Rules first, cheap filters next, the VLM last

A pipeline that spends expensive vision AI only where it adds value.

Select a step to see what happened.

Discover · How QA really judges a set

Sat with QA reviewers and photographers.

  • Style guides by category: sequence, shot types and quality standards.
  • Most common rejections: wrong order, model shots instead of flat lays, cropped edges, creases.
  • Where junk images entered the queue.

Deliverable: Rejection taxonomy and pipeline design.

Design · Guidelines as JSON

A machine-readable rulebook per category.

  • Required sequence with shot type and notes per position.
  • Quality standards: first image, negative space, creases, cropping, background.
  • Tiered pipeline so cheap checks run before the VLM.

Deliverable: Rulebook schema and rule registry.

Build · Scraper, router, gatekeepers, judge

End to end in one app.

  • Guideline scraper and VLM that writes the JSON rulebook.
  • Router matching each SKU to its rulebook; Tier 0, 1 and 1.5 gatekeepers.
  • Tier 2 VLM judge with per-rule scores, evidence and crop coordinates.

Deliverable: Working QC pipeline.

Adopt · Photographers see it first

Feedback before the set is struck.

  • Instant, explainable result per image set.
  • QA managers review the aggregated report and make the final call.
  • Rulebooks marked "AI draft" until Landmark reviews them.

Deliverable: Pilot results and studio SOP.

Scale · Every category and studio

Global alignment across studios.

  • Rule registry for all categories, versioned by season.
  • Agency submissions checked on upload.
  • QC report feeds the catalogue go-live process.

Deliverable: Roll-out plan.

02 · Routing & Tier 1 gatekeepers
Stop junk before it reaches the VLM
A batch of 50 SKUs arrives from the studio and an agency. The router matches each SKU to its rulebook; cheap gatekeepers check that each image decodes, meets resolution and file size, and actually shows the right garment. Only clean image sets go to the Tier 2 judge.

03 · Tier 2 VLM judge
Judge an image set against its rulebook
Pick a submitted set. Drag images to reorder, or use the menu under each image to break it (crop an edge, add creases, swap in a model shot). The judge re-checks sequence, shot type, cropping, creases, negative space and background, with evidence and crop coordinates.

Key Takeaways
What any e-commerce studio can borrow

    

      
01
Turn the guide into data first
A JSON rulebook is something every studio, agency and model can follow the same way.

      
02
Filter cheaply, judge carefully
Basic checks and small classifiers stop junk for a fraction of the cost of a vision model.

      
03
Explain every verdict
A score, an observation and the exact image and crop make the AI's call easy to trust and to act on.
